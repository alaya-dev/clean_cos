# UAT ToutDispo

Utiliser uniquement des données synthétiques et un environnement staging isolé. Pour chaque scénario : **pré-requis**, **données**, **étapes**, **résultat attendu**, **résultat constaté**, **pass/fail**, **testeur**, **date**, **preuve** et **défaut** sont obligatoires. Ne cocher aucun élément Meta live sans le dataset de test du propriétaire.

Les checklists storefront/admin/mobile sont exécutables maintenant; contenu/légal, production et Meta sont explicitement séparés.
