# Validation Meta production (différée)

Pré-requis : approbation propriétaire, HTTPS, token, Pixel, Test Event Code et
dataset de test. Exécuter les scénarios UAT Meta, comparer Test Events, ne
modifier ni catalogue, ni campagne, ni Converty. Documenter les preuves et
révoquer le code de test après validation.

Le Test Event Code n'est jamais envoyé en mode Production. Le passage en
Production demande un test serveur récent puis une seule confirmation explicite.
La validation ne doit modifier ni catalogue, ni campagne, ni Converty, ni
publicité active.
