# Créer le premier Super Admin

Pré-requis : accès shell contrôlé et identité propriétaire vérifiée. Créer via le seeder/commande approuvée, générer un mot de passe temporaire hors Git, exiger le changement au premier login, vérifier l’audit puis supprimer tout support temporaire. Ne jamais modifier directement le mot de passe en base.
